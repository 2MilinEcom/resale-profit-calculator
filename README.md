# Resale Profit Calculator

A small Python learning exercise that calculates resale profit after purchase costs, shipping, and selling fees.

## Technology

Python.

## Run locally

Run `python3 calculator.py`. Edit the example purchase price, selling price, shipping cost, and fees to explore the arithmetic. This is a beginner learning exercise.
